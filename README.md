# Ventilator Support Pro - Clinical Simulator

A professional, clinical-grade medical decision support tool and ventilator simulator designed for healthcare professionals. Built with React, TypeScript, and Tailwind CSS.

## 🚀 Quick Start

### Prerequisites
- **Node.js**: Version 18.x or higher
- **npm**: Version 9.x or higher

### Installation
1. Navigate to the project directory:
   ```bash
   cd ventilator-pro
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

### Development
To run the application in development mode with hot-reloading:
```bash
npm run dev
```
The app will be available at `http://localhost:5173`.

### Production Build
To create a production-optimized bundle:
```bash
npm run build
```
The output will be in the `dist/` directory.

---

## 🛠 Features
- **Modern Clinical UI**: Sophisticated design with glassmorphism and high-end iconography.
- **SBT Simulator**: Spontaneous Breathing Trial simulation with real-time timers and safety checklists.
- **Multi-language**: Full support for Turkish and English.
- **Medical Logic**: Advanced calculations for IBW, BSA, RSBI, and weaning assessments.

## ⚠️ Disclaimer
This application is for **educational and decision support purposes only**. All clinical decisions must be made by a qualified medical professional.
